# Business-Ideas
This is a place for all business calculators and systems to live 

## Tools
- [`deal-calculator/`](deal-calculator/index.html) — Main Street Deal Calculator: a Quick Screen (asking price, SDE, revenue, EBITDA → Great Deal / Research Deeper / Not Worthwhile, with reasons and a target offer price) plus full single-page underwriting for small-business acquisitions (sources & uses, payments by note, DSCR, cash flow after debt / manager, break-even, payback, multiples) across conservative / base / aggressive scenarios with red/yellow/green warnings. Open `index.html` in a browser; saved deals live in that browser's local storage.
